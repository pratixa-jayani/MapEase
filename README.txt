OSM Smart Explorer
==================

HOW TO RUN
1. Open this folder in Visual Studio Code.
2. Save index.html if prompted.
3. Install the Live Server extension in VS Code.
4. Right-click index.html and choose "Open with Live Server".
5. Ensure you have an internet connection.

FEATURES
- Responsive HTML/Tailwind interface
- Leaflet interactive map with OpenStreetMap tiles
- JavaScript input, change, submit and click events
- Input validation
- Fetch API and JSON handling with Nominatim and Overpass
- Loading, successful, empty-result, location-not-found and error states
- Results list with selectable map markers

NOTES
- External services require internet access and may be rate-limited or temporarily unavailable.
- Nominatim and Overpass are community services; use them responsibly and follow their usage policies.
- Map data attribution is displayed in the interface.
